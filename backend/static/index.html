LexGuard

An open-source legal-learning & case-reference platform that organizes information from official Indian sources into structured, understandable, and traceable records.

Collect → Structure → Simplify → Verify → Connect → Reference official sources

📌 Source Provenance

Records where legal information came from — source, publisher, official URL, retrieval date, and a stable file's SHA-256 hash.

🗂️ Structured Case References

Turns a judgment into an organized record with parties, facts, issues, provisions, actions, holdings, and review status.

🔐 Integrity & Review

SHA-256 hashing detects file changes/corruption alongside a formal review-status lifecycle — never a single "verified" claim.

Phase 1–3 Foundation. This front-end is an interactive prototype. Real validation, persistence, and integrity checks live in the FastAPI back-end (Pydantic schemas, SQLAlchemy models, Python SHA-256 service, and 16 automated tests).

                About & Disclaimer

                What LexGuard is

                LexGuard is an open-source legal learning and case-reference platform for India. It collects information from official sources, structures it into understandable records, and preserves the provenance chain back to those sources.

                What LexGuard is not

                • It is not an AI lawyer or legal-advice chatbot.
                • It does not predict case outcomes.
                • It is not a court-management or e-filing system.
                • It is not an official court website and claims no official court affiliation.
                • It never tells a user what to do in a specific case.
                • It does not replace an advocate, or databases like SCC Online, Manupatra, or eCourts.

                Technology

                • Back-end: FastAPI + SQLAlchemy 2.0 + Pydantic v2 + SQLite
                • Validation: Pydantic schemas with custom validators (slug, SHA-256, review status)
                • Integrity: Python SHA-256 service (chunked 8 KB reads)
                • Seeding: Transactional, idempotent seeding with audit reports and draft quarantine
                • Tests: 16 automated pytest tests (health, models, schemas, hash service)
                • Front-end: Vanilla HTML/CSS/JS prototype — no build step

                LexGuard provides educational legal information, not legal advice. Official sources remain authoritative at all times.
